# Titanic-Survival-Prediction
Developed a machine learning model to predict the survival of Titanic passengers based on demographic and socioeconomic features such as age, sex, and passenger class. Performed comprehensive data preprocessing including handling missing values, feature engineering, and exploratory data analysis. Implemented classification algorithms including Random Forest, Logistic Regression, and Decision Trees to build predictive models, achieving an accuracy of over 82%. Used Python libraries such as Pandas, Scikit-learn, and Matplotlib for data manipulation, modeling, and visualization. Delivered actionable insights into factors affecting survival rates, demonstrating strong skills in data cleaning, model training, evaluation, and reporting.
